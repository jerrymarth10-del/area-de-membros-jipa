PASSO A PASSO

1. Edite os textos, links do WhatsApp e links dos PDFs.
2. Coloque seus PDFs dentro da pasta materiais/ ou troque pelos links externos.
3. No checkout, configure o redirecionamento para /sucesso.html.
4. Suba tudo no GitHub.
5. Conecte o repositório na Vercel e publique.

IMPORTANTE
- Repositorio: deixe PRIVADO se nao quiser expor o codigo.
- Site na Vercel: sera PUBLICO para os clientes acessarem.
- Esta area de membros e simples, visual, e nao possui seguranca real.
- Para seguranca real, sera preciso backend e login verdadeiro.
